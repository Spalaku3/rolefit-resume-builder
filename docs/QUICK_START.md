# RoleFit: from ZIP to your own URL

The source is complete; it is not already deployed to your account.

## 1. GitHub

Unzip `rolefit-github-ready.zip`. Create an empty GitHub repository. Upload the
CONTENTS of `rolefit/` so that `app/`, `Dockerfile`, `requirements.txt` and
`render.yaml` are directly in the repository root. Include hidden files.
Never upload a real `.env`, personal resume, API key, private backup or database.

## 2. Persistent database

Create a free Neon PostgreSQL project. Click Connect and copy the full
connection string, including SSL parameters. Keep it secret.
Do not use SQLite on Render, and do not use the expiring free Render Postgres
instance as permanent resume storage.

## 3. Render

Connect your GitHub account in Render. Choose New -> Blueprint, select the
repository and review its `render.yaml`. Keep the service's plan set to Free.
Enter:

| Setting | What to enter |
|---|---|
| APP_PASSWORD | Your unique workspace password, 12+ characters |
| DATABASE_URL | The secret Neon PostgreSQL connection string |
| SESSION_SECRET | Generated by the Blueprint; no manual value needed |
| APP_TIMEZONE | America/Chicago by default; adjust as appropriate |

The Blueprint already sets production mode and secure cookies. Deploy.
When Render reports Live, open the actual service URL shown in its dashboard.
It resembles `https://YOUR-SERVICE-NAME.onrender.com`; this is only an example.
Sign in with your workspace password.

## 4. Try the app without AI keys

Use the fictional sample profile/job and select Local tailoring. Generate a
resume, open its preview, then try PDF and DOCX export. Replace the fictional
profile with your own before submitting any application.

## 5. Enable AI

Add these as secrets in Render -> your service -> Environment, then redeploy:

- GROQ_API_KEY, and GROQ_FREE_TIER_CONFIRMED=true after checking your Groq account's free plan.
- OPENROUTER_API_KEY for optional fallback to allowlisted zero-price :free models.

Enable your configured providers and Automatic fallback in the app's settings.
Choose AI tailoring and confirm sharing relevant document excerpts.
Free-provider availability is not guaranteed. The app will not silently select
paid alternatives, but it cannot verify Groq's billing plan or control account
hosting overages. Check your external account billing/spending controls.

## 6. Use your resume and images

Upload your master DOCX, review extracted text and save the confirmed profile.
Open Images & certifications to review and select extracted badges or upload
PNG/JPG/WebP images. AWS Developer and Oracle Java art can be fetched from the
allowlisted issuer sources; existing Azure art can be imported from DOCX.
Use only credentials you actually earned and are entitled to display.

Choose a 5-, 6- or 7-page target, Reference template and your preferred font.
Paste/upload the job description and generate. The master stays unchanged.
Short sources are not padded. Word may paginate differently from the exact
PDF preview when fonts differ. Use ATS Clean for an image-free export.

## Important

The score is a local heuristic, not a guaranteed employer ATS score above 90.
The 15/day cap counts successful AI/local generations; retries count once,
failures zero. Editing, copies and exports do not use the generation cap.

Render Free sleeps after idle time; opening it can require a short wake-up.
Neon persists the data across restarts, within its own free-plan limits.
Review README.md and docs/VERIFICATION.md before relying on the app.
